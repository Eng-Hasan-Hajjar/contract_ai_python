# 📌 نبذة عن المشروع

يهدف مشروع **Contract AI Python** إلى إنشاء نظام ذكي لتحليل العقود والملفات القانونية باستخدام تقنيات الذكاء الاصطناعي ومعالجة اللغة الطبيعية (NLP)، وذلك لتسهيل فهم العقود واستخراج المعلومات المهمة بشكل آلي واحترافي.

يساعد هذا النظام في:

- تحليل العقود القانونية تلقائياً
- استخراج البنود المهمة
- اكتشاف المخاطر القانونية المحتملة
- تلخيص العقود باستخدام الذكاء الاصطناعي
- البحث الذكي داخل العقود
- تسريع عملية مراجعة الوثائق القانونية

# 🚀 المميزات الرئيسية

## ✅ مميزات النظام

- استخراج النصوص من ملفات العقود
- تحليل العقود باستخدام الذكاء الاصطناعي
- اكتشاف البنود والشروط المهمة
- تقييم المخاطر القانونية
- إنشاء ملخصات ذكية للعقود
- استخراج الكلمات المفتاحية
- دعم ملفات PDF و DOCX
- واجهات API احترافية
- بنية قابلة للتطوير
- دعم التكامل مع نماذج الذكاء الاصطناعي الحديثة
