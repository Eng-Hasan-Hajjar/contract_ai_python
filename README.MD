⚙️ طريقة التثبيت
1️⃣ استنساخ المشروع
git clone https://github.com/Eng-Hasan-Hajjar/contract_ai_python.git
2️⃣ الدخول إلى مجلد المشروع
cd contract_ai_python
3️⃣ إنشاء بيئة افتراضية
python -m venv venv
4️⃣ تفعيل البيئة الافتراضية
ويندوز
venv\Scripts\activate
لينكس / ماك
source venv/bin/activate
5️⃣ تثبيت المكتبات المطلوبة
pip install -r requirements.txt
▶️ تشغيل المشروع
python main.py

أو باستخدام:

uvicorn app.main:app --reload
